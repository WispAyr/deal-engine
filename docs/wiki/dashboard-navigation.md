# Dashboard & Navigation

## Main Nav (Header)

| Tab | Description |
|-----|-------------|
| **Dashboard** | Summary stats, map, listing counts |
| **Towns** | Per-town market info, price history |
| **Prompts** | Deal cards (town × property type), intel, strategies |
| **Shortlist** | Saved deals |
| **Auctions** | Auction listings |
| **Bridge** | Bridge-finance suitable properties |
| **Comps** | Full listings/rentals table |
| **Strategies** | Strategy Builder flow editor |

## Filters (Header)

- **Search** — Towns, strategies, addresses
- **Strategy** — BTL, BRRR, Flip, HMO, SA
- **Type** — Flat, House, Detached, Semi, Terraced
- **#** — Bedrooms (1, 2, 3, 4+)

## Sidebar

- **Live Intel** — Main feed
- **Shortlist** — Saved deals
- **Admin Dashboard** — Sync, user management
- **Target Towns** — Switch active town
- **Force Sync DB** — Trigger Rightmove sync

## Property Cards (Prompts)

Each card = town + property type (e.g. "Ayr – 2-bed flat"). Click to expand:

- **Intel** — Buy band, rent, yield, deal rule
- **Mkt** — Market stats, listings, rentals
- **BTR / BTF / BRRR / HMO / SA** — Strategy tips
- **★** — Add to shortlist
